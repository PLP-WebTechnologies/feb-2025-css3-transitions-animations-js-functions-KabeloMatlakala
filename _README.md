# 🎯 CSS3 Transitions, Animations & Advanced JavaScript Assignment

Welcome to your interactive web playground! 🎉  
This project focuses on mastering **CSS transitions & animations**, using **JavaScript functions for dynamic interactivity**, and applying **localStorage** for persistent user preferences.

---

## 📁 Project Structure

```
📂 📂 js-transitions-assignment/
├── index.html         # Your playground – where it all comes together
├── style.css          # Keep it cute (optional but encouraged)
└── script.js          # The JavaScript wizardry happens here
```


---

## 🧩 Objectives

- ✅ Create smooth CSS transitions and animations
- ✅ Use JavaScript functions to trigger visual changes and handle user interactions
- ✅ Store and retrieve user preferences using `localStorage`

---

## 🛠️ What’s Included

### ✅ 1. CSS3 Transitions & Animations

- Button hover effects using `:hover` and `transition`
- Keyframe animations like `.magic-pop` for click feedback
- Accordion content fade-in using `@keyframes fadeIn`

### ✅ 2. Advanced JavaScript Functions

- Event listeners for click, hover, double-click, and keypress (`keydown`)
- Functions to trigger animations by adding/removing classes
- Theme toggler and gallery view switcher using JS

### ✅ 3. Persistent Preferences with localStorage

- Saves and loads **dark/light theme**
- Saves **gallery layout mode** (grid or list)
- Preferences persist even after page reloads

- Keep your CSS modular and animation names clear.
- Use functions to keep JS reusable and clean.
